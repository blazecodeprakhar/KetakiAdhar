# Changelog

All notable changes to the Ketaki Adhar platform are documented in this file.

## [2.1.0] - 2026-11-07

### Added
- **Multi-Lingual Localization**: Added complete English, Marathi (मराठी), Kannada (ಕನ್ನಡ), and Hindi (हिंदी) language translation suite.
- **LanguageSelector**: Desktop dropdown and dedicated mobile drawer grid with active language indicator.
- **Patronage Pledge Model**: Built `/donate` page supporting strategic pillars without transactional checkout or price tags.
- **Volunteer Portal**: Built `/volunteer` with interest tagging, scheduling, and registration.
- **Farmer Intake Form**: Implemented 8-field farmer intake form on the Home page (`/`) including acreage and photo upload.

### Fixed
- **Contrast**: Resolved text visibility issues on hero banners by setting fallback dark hex gradients (`#02241b`).
- **Footer Localization**: Fully translated office address, headers, legal links, and copyright text across all languages.
- **Navigation**: Enhanced `ScrollToTop` to support smooth scrolling to hash anchors across routes (`/#why-farmers`, `/#initiatives`, `/our-story#programs`).
- **Contact**: Standardized all contact emails to `info@ketakiadhar.in`.
