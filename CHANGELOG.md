# Changelog

All notable changes to the Ketaki Adhar web platform are documented in this file.

## [2.1.0] - 2026-11-08
### Added
- Direct form hash navigation for all Donate and Volunteer buttons.
- Form arrival attention pulse and first-input auto-focus.
- Dynamic completion progress bar with realtime checkmarks.
- Full multi-language translations for Marathi, Kannada, and Hindi.
- First-time visitor language selection popup.
- Toast notifications across all forms.
- Reusable ErrorBoundary and OfflineBanner components.
- Schema.org JSON-LD structured data and SEO meta tags.
- Comprehensive unit tests and architecture documentation.

### Changed
- Standardized organization email to `info@ketakiadhar.in`.
- Transformed donation flow into strategic patron pledges without price cards.
