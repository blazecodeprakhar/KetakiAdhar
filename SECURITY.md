# Security Policy

## Reporting Security Issues

Ketaki Adhar takes security seriously. If you discover a vulnerability or potential security flaw, please report it privately:

* **Email**: [info@ketakiadhar.in](mailto:info@ketakiadhar.in)
* **Subject**: `[SECURITY VULNERABILITY] Ketaki Adhar Platform`

Please do not open public issues regarding undisclosed vulnerabilities. Our team will review and respond promptly.
